# Portfolio Screenshots Checklist

Recommended screenshots for a portfolio/GitHub release presentation of
Phase 4. This is a checklist only — **no images are generated by this
document or this milestone**; capture each manually when preparing the
release.

## Checklist

- [ ] **Project folder structure** — top-level tree (e.g. `tree /F` on
      Windows or `tree -L 2` on Unix) showing `src/`, `api/`, `data/`,
      `models/`, `reports/`, `docs/`, `demo/`, `scripts/`, `tests/`.
- [ ] **Warehouse reports** — `reports/warehouse_loading/validation_report.md`
      rendered (shows PASS on all PK/FK/NULL checks).
- [ ] **Feature engineering reports** — `reports/features/feature_statistics.md`
      or `reports/model_discovery/feature_dataset_inventory.md` rendered.
- [ ] **Model comparison reports** — `reports/models/leaderboard.md` and
      `reports/models/comparison.md` rendered (best model per task, full
      metrics table).
- [ ] **API Swagger UI** — `http://127.0.0.1:8000/docs` with the FastAPI
      server running (`uvicorn api.main:app --reload`), showing all 5
      `/predict/*` endpoints and the `/health` endpoint expanded.
- [ ] **Example prediction requests** — Swagger UI's "Try it out" panel (or
      a terminal `curl` command) for at least one endpoint, showing the
      request body from `demo/sample_requests/`.
- [ ] **Example prediction responses** — the corresponding response panel
      or terminal output, matching `demo/sample_responses/`.
- [ ] **Test results (75/75)** — terminal output of `pytest tests/ -v`,
      full pass summary line visible (`75 passed`).
- [ ] **Coverage report (if available)** — terminal output of
      `pytest tests/ --cov=src --cov=api --cov-report=term-missing`, or an
      `htmlcov/index.html` screenshot if HTML coverage was generated.

## Notes

- Prefer terminal screenshots with a readable font size and full command
  visible above the output, so a viewer can reproduce what's shown.
- For Swagger UI screenshots, use `http://127.0.0.1:8000/docs` (FastAPI's
  built-in interactive docs, auto-generated from `api/schemas.py` — no
  extra setup needed).
- Store captured images outside this repository unless the project decides
  to commit them (not part of this milestone's scope) — this file only
  defines what to capture, not where to store the resulting images.
